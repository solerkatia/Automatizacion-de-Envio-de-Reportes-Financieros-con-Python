# Automatizacion-de-Envio-de-Reportes-Financieros-con-Python
Este proyecto demuestra habilidades de automatización de procesos mediante la combinación de librerías en Python. Toma datos calculados de un análisis financiero (como cotizaciones máximas, mínimas y valores medios de una acción bursátil) y los redacta automáticamente en la interfaz web de Gmail.
